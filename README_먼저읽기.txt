폐의약품 조례 웹사이트 프로토타입

1. 가장 쉬운 실행 방법
- 이 폴더를 PC에 압축 해제합니다.
- index.html을 더블클릭하면 브라우저에서 바로 열립니다.
- 수정할 때는 VS Code로 폴더 전체를 엽니다.

2. 파일 역할
- index.html : 페이지의 내용과 섹션
- style.css  : 색, 글꼴, 간격, 모바일 화면 디자인
- script.js  : 필터, 지역검색, 타일 클릭 기능
- data.js    : 엑셀에서 변환된 지자체 데이터

3. 현재 프로토타입에 들어간 기능
- 문제제기
- 4개 조례유형 숫자 요약
- 230개 시군구 타일 시각화 및 유형 필터
- 타일 클릭 상세정보
- 속초시-양양군 비교
- 시도 → 시군구 연동 검색
- 문제 제기/캠페인 메시지

4. 다음 단계
- 실제 대한민국 시군구 GeoJSON 확보 및 2026 행정구역과 매칭
- 진짜 지도형 choropleth 구현
- 캠페인 문구/출처/단체명/로고 확정
- GitHub Pages 업로드
- 공개 URL로 QR 코드 생성
